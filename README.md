# 🎵 TASK 4: Music Player using JavaScript

## 📌 Project Overview

This project is a **Music Player Web Application** built using **HTML, CSS, and JavaScript**.  
It allows users to play songs with full controls like **play, pause, next, previous, volume control, and progress tracking**.

The main goal of this project is to understand **audio handling in JavaScript, DOM manipulation, and UI interactivity**.

---

### 🎧 Audio Controls
- ▶️ Play / Pause music
- ⏭️ Next song

## ⚙️ How It Works

### 🎵 Audio Playback
- JavaScript `Audio()` object is used
- Songs are loaded dynamically from playlist array
- Controls update audio state (play/pause/skip)

---

### 📊 Progress Bar
- Updates in real-time using `timeupdate` event
- Shows current time vs total duration
- User can seek by clicking/dragging

---

### 🔁 Playlist System
- Songs stored in an array
- Index-based navigation (next/previous)
- Auto switch to next song when current ends

---

## 💡 Key Concepts Used

- HTML Audio API
- Event Listeners (click, timeupdate, ended)
